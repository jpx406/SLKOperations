## Decisions (user, 2026-10-24)

| topic | decision | what it means for the build |
| --- | --- | --- |
| Bonus rules | **Configurable rules** | Admin screen with one pool rule per WIREGUARD job type (fixed USD per job, per run, or % of job revenue) and default crew splits by role. The real numbers are entered by NESR, never hard-coded. Closure gets the Crew Assignment & Bonus Distribution section (Admin/SDM). Bonus Report and Bonus Analysis read the approved lines |
| Revenue | **Entered on each job** | `jobs.revenue_cents` + `revenue_currency` on Closure (Admin/SDM/Sales). The Sales Dashboard is an aggregate of job revenue: per account group, Analysis, Incomplete Data = completed jobs without revenue. Find/Edit Job opens the job; no separate dataset, so no "+ Add Jobs" or "Upload Clean Revenue". Bonus % of Revenue = approved bonus ÷ revenue of the same jobs, against the < 4.5 % target |
| AI Agent | **Yes, as a later milestone** | Read-only tools scoped by the caller's menus and countries; `ai_settings` (on/off, model, monthly USD budget shared with the help assistant, messages per user per day); usage ledger; per-user grant through the `ai_agent` menu |
| Countries | **Set by the SLK Ops admin** | `user_roles.countries` becomes admin-owned (multi-select in Users & Roles; choices = the countries in the WIREGUARD units). First sign-in seeds it from WIREGUARD, and later sign-ins no longer overwrite it. Every request reads it from the database, so a change applies on the next click |
| Pre-Job Notes access | follow the manual (not asked separately) | Admin + SDM + people on the **active SLK Contacts list**, plus the per-person grant. The SLK supervisor and deputy SDM defaults are removed; grant them individually if wanted |

## Not affected

The other Operation tabs, Service Quality, Inventory, Knowledge Hub and Attendance's grid are unchanged by the Administrator Manual.
